Reproducibility status
----------------------
The historical Colab run is partially reproducible from the evidence above,
but it is not a complete dependency lock because TensorFlow and scikit-learn
were imported without their versions being printed. The saved model can still
be loaded by the current local environment, whose pinned direct dependencies
are in requirements-local.txt.

Required capture cell before any new Colab training run
-------------------------------------------------------
Run the following in the Colab notebook and save the output alongside the
experiment artifacts:

    import sys, platform, subprocess
    print("python:", sys.version)
    print("platform:", platform.platform())
    print("tensorflow:", __import__("tensorflow").__version__)
    print("keras:", __import__("keras").__version__)
    print("numpy:", __import__("numpy").__version__)
    print("pandas:", __import__("pandas").__version__)
    print("scikit-learn:", __import__("sklearn").__version__)
    print("gpu:")
    subprocess.run(["nvidia-smi", "--query-gpu=name,driver_version,memory.total",
                    "--format=csv,noheader"], check=False)
    subprocess.run([sys.executable, "-m", "pip", "freeze", "--all"], check=False)

Save the complete output as a versioned artifact, for example:
research/artifacts/colab_freeze_<date>.txt

Interpretation
--------------
Do not silently mix the Colab training environment and the local inference
environment. Record the environment ID with every model, detector seed, and
experiment result. API keys and secrets must never be included in a freeze.
